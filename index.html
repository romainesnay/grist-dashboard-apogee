Ce tableau de bord permet d'analyser les effectifs inscrits à l'UM à partir des extractions du logiciel APOGEE (via AMPHI).

Les axes analysés sont : les composantes (UEI), les diplômes, les années de diplôme, les parcours/étapes, les profils étudiants et les régimes d'inscription.

Précisions méthodologiques

  • Il est possible de croiser les informations en utilisant les filtres bleus et roses, ou en cliquant directement sur une barre d'un graphique (cross-filtering).
  • Le filtre Doublon permet d'isoler les inscriptions principales des étudiants ayant plusieurs inscriptions la même année (ex. : étudiant inscrit en BUT 3 à l'IUT de Nîmes et en L3 à l'IAE).
  • Les colonnes Diplôme et Année de diplôme mettent en avant les diplômes principaux utilisés pour l'apprentissage ; les autres formations (DU, C2I, thèses, etc.) sont regroupées dans AUTRE.

Guide des filtres

  • Régime d'inscription (lib.) : filtre les grands régimes d'inscription (apprentissage, formation continue, initiale, etc.).
  • Profil étudiant (lib.) : précise le régime d'inscription (permet notamment de distinguer les apprentis App.CFA LR).
  • Composante (lib.) : indique l'UEI de rattachement (FDS, IAE, IUT, Polytech, Médecine, etc.).
  • Diplôme / Année de diplôme : précise le niveau et le type de diplôme (L1–L3, M1–M2, BUT1–BUT3, LP, ING, AUTRE).
  • Année de l'inscription : indique l'année universitaire d'inscription.
  • Doublon : filtre les étudiants inscrits plusieurs fois la même année (Unique vs Doublon).
  • Statut Initial : filtre les formations (étapes) selon la présence ou non d'étudiants en formation initiale.
  • Statut FC : filtre les formations selon la présence ou non d'étudiants en formation continue.
  • Statut apprentissage : filtre les formations selon la présence ou non d'étudiants en apprentissage (affiche tous les publics des formations mixtes).
